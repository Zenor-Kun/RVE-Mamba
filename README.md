# RVE-Mamba: Reliable Audio-Visual Evidence Modeling for Multimodal Depression Detection

RVE-Mamba investigates reliability-aware audio-visual evidence modeling for multimodal depression detection. The framework introduces an Evidence Family Selector (EFS) to organize dataset-level selection between two complementary evidence modeling paths: the Stable Evidence Family (SEF) for reliable expert-output fusion and the Adaptive Cross-modal Evidence Family (ACEF) for fine-grained audio-visual representation learning. The project provides reliability-aware expert selection and fusion, cross-modal state-space interaction, fractional-domain feature enhancement, and long-range temporal modeling on D-Vlog and LMVD.

This paper is currently under review at **Neurocomputing**.
